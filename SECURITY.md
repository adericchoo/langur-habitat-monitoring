# Security & sensitive-data policy

This project monitors the **Critically Endangered Delacour's langur**. Precise coordinates
of langur populations or active threats are **poaching-sensitive** and must **never** be
committed to this public repository.

## Rules

- **No precise locations in git.** Exact coordinates of langur sightings, roosts, or active
  threats (logging, snaring, encroachment) never enter this repo — not in data files, code,
  issues, PRs, commit messages, or screenshots.
- **Repo data is aggregated/coarsened only.** Anything committed here is spatially
  aggregated or coarsened so it cannot reveal a precise location.
- **Fine-grained data is access-controlled.** Raw, high-resolution, and precise-location
  data lives in access-controlled storage, gated by Save Vietnam's Wildlife (SVW) — never
  in git.

## Responsible disclosure

If you discover a vulnerability, or any sensitive data that has been committed by mistake,
please **email the maintainer at `<maintainer-email>`** rather than opening a public issue.
We will respond as quickly as we can.
